# Getting Support for Cline Marketplace

Thank you for using **Cline Marketplace Local Browser & Control Plane**.

Here are the best ways to get help, find answers to your questions, or report issues:

---

## 1. Documentation & Troubleshooting

Before opening an issue, please check:
- [README.md](./README.md): Comprehensive quick start, architecture, API reference, and configuration.
- [Troubleshooting Matrix](./README.md#troubleshooting-matrix): Solutions for common CLI path, permission, and port issues.
- [Diagnostics Tab in Web GUI](http://127.0.0.1:5173): Click **Health** in the top navigation to inspect runtime binaries, paths, and storage roots.

---

## 2. Reporting Bugs & Asking Questions

- **Bug Reports**: If you've found a bug or error, please open a [Bug Report](https://github.com/Mateo-Piedra22/ClineMarket/issues/new?template=bug_report.yml).
- **Feature Suggestions**: Propose new primitives, bundles, or automations via [Feature Request](https://github.com/Mateo-Piedra22/ClineMarket/issues/new?template=feature_request.yml).
- **General Questions**: Open a [Question & Support Issue](https://github.com/Mateo-Piedra22/ClineMarket/issues/new?template=question.yml).

---

## 3. Official Cline Documentation

For issues related to the upstream Cline Bot extension, model keys, or CLI installation:
- Official Website: [https://cline.bot](https://cline.bot)
- Documentation: [https://docs.cline.bot](https://docs.cline.bot)
- Upstream Registry: [https://github.com/cline/marketplace](https://github.com/cline/marketplace)
